# 已完成案例：ULJS00354 到 HD8.6

这是 2026-10-15～16 的工程记录摘要，用来说明流程的证据和量级。并非可直接应用到任意 ISO 的兼容承诺；不附带游戏镜像、专有生成代码、音画素材或个人存档。

## 输入与执行路线

用户提供的《科学超电磁炮》简体中文、内封 DLC 镜像，ID 为 ULJS00354。主程序实测为明文 ELF32 小端 MIPS/PRX，2 个加载段、45,108 条重定位、263 个导入，无可恢复原开发工程的符号信息。镜像身份不证明所有 DLC 路径可用。

路线为 psprism 生成 C++20，加上修改过的 Refract Windows D3D11/XAudio2 运行时，再编成本机 EXE；部分指令存在解释器兜底，因此不是“彻底去掉一切兼容层”。没有把 PPSSPP 换图标称为原生移植。

这次用到 LLVM-MinGW 20261006、CMake 4.4.4、Ninja 1.13.2；构建参数和版本仅用于重现本次记录。最终增加的 libwebp 为 1.6.0，静态链接 decoder，PNG 使用 Windows WIC；没有额外 WebP DLL。未来执行需按当前项目核实兼容版本。

## 工程顺序与非显然经验

| 问题/需求 | 本次处理与验证 | 可复用经验 |
|---|---|---|
| 标题或剧情黑屏 | 从实际运行日志定位线程/HLE、内存和绘制语义，逐个补齐 | 空壳 EXE 不是移植完成，不能通过禁用失败路径假装可玩 |
| 原鼠标输入 | 滚轮移动高亮、左键确认/对白、中键 START、右键返回；独立状态和短按锁存 | 鼠标按键映射不同于点击菜单文字坐标；描述要准确 |
| 第一章人物背景缺失 | 证据显示 4×4 BEZIER 命令被忽略；补本作 2D through 三角曲面绘制，再实测恢复人物背景 | 应补缺失几何，先于批量放大素材；未证明 3D/Spline 通用支持 |
| 柔和文字/UI | 依据纹理身份、UV/区域、颜色与绘制对，调整高亮/正文和面板；保留原画质对照 | 不将所有白色像素一律替换，不修改未知 UI |
| AUTO/SKIP | 接入原游戏查询和等待；保留语音/阅读节奏，不模拟高速确认 | 选择、暂停/回看和弹窗要取消；鼠标后台保持与 Ctrl 前台临时模式分开 |
| 全量高清 | 2335 个 GRP 项中 1665 个 raster 条目；1514 个唯一原图身份，274 个完整场景先合成再增强拆分 | 档案项数、唯一纹理数、最终文件数是不同统计口径 |
| 字库 | 3700 格完整字库，144 格已认可字形保留；有准确映射的重绘，未知/映射不可靠的保留字形 | Unicode 表不是自动正确的答案，不能凭外观乱换字 |
| 动态表情 | 108 个基础图集；按字节验证同图集脸/嘴复制区域；六个真实捕获样本回归 | 静态 hash 覆盖不了可变图集；修接缝不能洗掉无关高清细节 |
| ISO 去重 | 同一 ISO 同时支持文件与扇区读取；31 个资源文件约 1.04 GB 经实际 HLE 与原解包内容逐字节一致 | 先实现/验证运行时，再移除发布包的重复解包资源 |
| 无损压缩 | 先 PNG，再 WebP，透明区 RGB 一并比较，保留更小的格式 | `.rgba` 名称可保持，运行时根据 magic 判格式；扩展名不是解码证据 |

## 真实瘦身结果

| 版本 | 变化 | ZIP 字节 | 解压字节/约值 |
|---|---|---:|---:|
| HD8.3 | 完整高清便携版，ISO 与解包资源重复 | 3,729,294,807 | 约 7.594 GB |
| HD8.4 | ISO 统一读取，去掉解包副本 | 2,855,504,544 | 6,555,302,081 |
| HD8.5 | 高清 RGBA 换 PNG 无损存储 | 2,224,689,212 | 2,419,062,816 |
| HD8.6 | 1638 张无损 WebP、1 张 PNG | 1,894,939,666 | 2,089,249,194 |

GB 采用十进制。HD8.6 比 HD8.5 下载少 329,749,546 字节（14.82%），相对最初包少 49.19%。这不是其他游戏可预期的比例。

最终纹理目录含 1639 个像素文件与 7 个配置文件，从原 RGBA 5,467,227,143 字节，到 PNG 1,330,949,587，再到混合无损存储 994,264,845。全部 5,466,402,816 字节 decoded RGBA 通过生产加载器逐字节一致。

一次配对全包校验累计解码：混合新版 22.14 秒、PNG 对照 35.24 秒；新版单文件最高约 1.94 秒。全包总时间更短不意味着每张都更快，也不是游戏加载/帧率实测。最终包 1668 个条目的完整清单/大小/唯一性/CRC 均通过，staging 与已验证输入另做 SHA-256 比较。

## 保留的限制

- 原生基线和 HD6 曾实测进入第一章；HD8.3 的后台 AUTO/SKIP 有独立窗口观察。未实际遇到的剧情选项，其停止行为只有定向回归证据。
- 最后几轮压缩遵从用户自行试玩的选择，没有再启动、操作、截图或关闭游戏窗口。HD8.6 因此是已完成资源/打包验证的候选，不是再次完成全剧情实测。
- 视频未启用；其他电脑、所有剧情/小游戏、完整存读档与通关稳定性未全部验收。不能以原生构建和完整资源包掩盖这些缺口。
- 原画质鼠标早期 EXE 留作历史对照，但含旧画面问题。新的原画质轻量版应沿用当前修复后的运行时，去掉高清资源，不能简单重新发旧 EXE。
- 原始 ISO、旧包、高清源文件、普通入口和个人存档保留。本次仅本地交付，没有自动上传或发送给朋友。

本次底层经验来自本地构建日志、全量生产加载器比对、字库/表情真实 fixture、打包 manifest 和 CRC 记录。skill 本身提供流程和通用工具，不自带本作全部运行时补丁；重做此作时应接入原项目源码/补丁，新游戏则重定位和重验。
